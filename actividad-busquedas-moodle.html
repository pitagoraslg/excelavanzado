Búsquedas en Excel con BUSCARX

Usarás solo BUSCARX para encontrar los datos de una reclamación de 3 formas distintas.
🪪 1 · Por cédula
Escribes una cédula y traes el ID, el afiliado, la ARS y el monto.		 🧾 2 · Por ID
Escribes un ID y traes todos los datos con una sola fórmula.		 👤 3 · Por afiliado
Escribes un nombre y traes su ID, cédula, ARS y monto.

📝 Lo que tienes que hacer

  1. Descarga la base de Excel y guárdala como Apellido_Nombre_Busquedas.xlsx.
  2. Descarga las instrucciones en PDF y sigue las 3 partes clic a clic. Cada parte va en su propia hoja: CEDULA, ID y AFILIADO.
  3. Compara tus resultados con los que indica el PDF y haz las pruebas que trae cada parte.
  4. Sube tu archivo Apellido_Nombre_Busquedas.xlsx en esta tarea.
⬇ Instrucciones (PDF) ⬇ Base de Excel

Requiere Microsoft 365, Excel 2021 o Excel para la web.
